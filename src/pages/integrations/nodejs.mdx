Send traces and metrics from a Node.js app to Hosted OpenTelemetry with the zero-code register hook. Do not install `otelcol-contrib` for this path.

## Endpoint

- Endpoint: `https://@logs_id-otel.logit.io` (no port)
- Protocol: `http/protobuf`
- Username: `@logs_id-otel`
- API key: the key on the Hosted OpenTelemetry card (Settings, Endpoints). Replace `<your-api-key>`. Do not commit that key.
- Header: `Authorization=Basic%20` plus the Base64 of `username:api-key`.

`@logs_id` is your logs stack id. Do not set the endpoint in code. Do not use gRPC to this host.

Set the variables on the process that runs the app. An export in the current terminal only applies to a local run in that same window.

<Tabs items={["Linux and macOS", "Windows PowerShell"]}>
<Tab>

```bash copy /@logs_id/
export OTEL_SERVICE_NAME="my-service"
export OTEL_TRACES_EXPORTER="otlp"
export OTEL_METRICS_EXPORTER="otlp"
export OTEL_LOGS_EXPORTER="otlp"
export OTEL_EXPORTER_OTLP_ENDPOINT="https://@logs_id-otel.logit.io"
export OTEL_EXPORTER_OTLP_PROTOCOL="http/protobuf"
export OTEL_EXPORTER_OTLP_HEADERS="Authorization=Basic%20$(printf '%s:%s' '@logs_id-otel' '<your-api-key>' | base64 | tr -d '\n')"
```

</Tab>
<Tab>

```powershell copy /@logs_id/
$env:OTEL_SERVICE_NAME = "my-service"
$env:OTEL_TRACES_EXPORTER = "otlp"
$env:OTEL_METRICS_EXPORTER = "otlp"
$env:OTEL_LOGS_EXPORTER = "otlp"
$env:OTEL_EXPORTER_OTLP_ENDPOINT = "https://@logs_id-otel.logit.io"
$env:OTEL_EXPORTER_OTLP_PROTOCOL = "http/protobuf"
$pair = "@logs_id-otel:<your-api-key>"
$env:OTEL_EXPORTER_OTLP_HEADERS = "Authorization=Basic%20" + [Convert]::ToBase64String([Text.Encoding]::UTF8.GetBytes($pair))
```

</Tab>
</Tabs>

<Steps>
  ## Register hook

  ```bash copy
  npm install @opentelemetry/api @opentelemetry/auto-instrumentations-node
  node --require @opentelemetry/auto-instrumentations-node/register app.js
  ```

  Set `OTEL_TRACES_EXPORTER=otlp`, `OTEL_METRICS_EXPORTER=otlp` and `OTEL_LOGS_EXPORTER=otlp` with the shared `OTEL_EXPORTER_OTLP_*` variables. The Node.js getting started steps instrument traces and metrics and the logging library is still under development, so do not invent a logs SDK call and do not install a Collector to cover logs.

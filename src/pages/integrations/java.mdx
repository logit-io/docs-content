Send logs, traces and metrics from a Java app to Hosted OpenTelemetry with the Java agent. There is no path that skips the agent. Do not install `otelcol-contrib` for this path.

## Endpoint

- Endpoint: `https://@logs_id-otel.logit.io` (no port)
- Protocol: `http/protobuf`
- Username: `@logs_id-otel`
- API key: the key on the Hosted OpenTelemetry card (Settings, Endpoints). Replace `<your-api-key>`. Do not commit that key.
- Header: `Authorization=Basic%20` plus the Base64 of `username:api-key`.

`@logs_id` is your logs stack id. The agent reads `OTEL_SERVICE_NAME`, `OTEL_EXPORTER_OTLP_ENDPOINT`, `OTEL_EXPORTER_OTLP_PROTOCOL` and `OTEL_EXPORTER_OTLP_HEADERS`. Do not add a port. Do not use gRPC to this host. Do not set the endpoint with a `-Dotel.exporter.otlp.endpoint` that is only the bare host.

Set the variables on the process that runs the JVM. An export in the current terminal only applies to a local run in that same window.

<Tabs items={["Linux and macOS", "Windows PowerShell"]}>
<Tab>

```bash copy /@logs_id/
export OTEL_SERVICE_NAME="my-service"
export OTEL_EXPORTER_OTLP_ENDPOINT="https://@logs_id-otel.logit.io"
export OTEL_EXPORTER_OTLP_PROTOCOL="http/protobuf"
export OTEL_EXPORTER_OTLP_HEADERS="Authorization=Basic%20$(printf '%s:%s' '@logs_id-otel' '<your-api-key>' | base64 | tr -d '\n')"
export JAVA_TOOL_OPTIONS="-javaagent:path/to/opentelemetry-javaagent.jar"
java -javaagent:path/to/opentelemetry-javaagent.jar -jar myapp.jar
```

</Tab>
<Tab>

```powershell copy /@logs_id/
$env:OTEL_SERVICE_NAME = "my-service"
$env:OTEL_EXPORTER_OTLP_ENDPOINT = "https://@logs_id-otel.logit.io"
$env:OTEL_EXPORTER_OTLP_PROTOCOL = "http/protobuf"
$pair = "@logs_id-otel:<your-api-key>"
$env:OTEL_EXPORTER_OTLP_HEADERS = "Authorization=Basic%20" + [Convert]::ToBase64String([Text.Encoding]::UTF8.GetBytes($pair))
$env:JAVA_TOOL_OPTIONS = "-javaagent:path/to/opentelemetry-javaagent.jar"
java -javaagent:path/to/opentelemetry-javaagent.jar -jar myapp.jar
```

</Tab>
</Tabs>

<Steps>
  ## Java agent

  Download `opentelemetry-javaagent.jar` from the opentelemetry-java-instrumentation releases and start the JVM with it.

  ```bash copy
  export JAVA_TOOL_OPTIONS="-javaagent:path/to/opentelemetry-javaagent.jar"
  java -javaagent:path/to/opentelemetry-javaagent.jar -jar myapp.jar
  ```

  Protocol `http/protobuf` sends logs, traces and metrics with OTLP HTTP.

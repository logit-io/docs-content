Send logs, traces and metrics from a PHP app to Hosted OpenTelemetry. The PECL extension is required. Do not install `otelcol-contrib` for this path.

## Endpoint

- Endpoint: `https://@logs_id-otel.logit.io` (no port)
- Protocol: `http/protobuf`
- Username: `@logs_id-otel`
- API key: the key on the Hosted OpenTelemetry card (Settings, Endpoints). Replace `<your-api-key>`. Do not commit that key.
- Header: `Authorization=Basic%20` plus the Base64 of `username:api-key`.

`@logs_id` is your logs stack id. Do not set an endpoint in code. Do not use gRPC to this host.

Set the variables on the process that runs PHP (php-fpm pool env, Apache `SetEnv`, or the process manager). An export in the current terminal only applies to a local run in that same window.

<Tabs items={["Linux and macOS", "Windows PowerShell"]}>
<Tab>

```bash copy /@logs_id/
export OTEL_SERVICE_NAME="my-service"
export OTEL_PHP_AUTOLOAD_ENABLED="true"
export OTEL_TRACES_EXPORTER="otlp"
export OTEL_METRICS_EXPORTER="otlp"
export OTEL_LOGS_EXPORTER="otlp"
export OTEL_EXPORTER_OTLP_ENDPOINT="https://@logs_id-otel.logit.io"
export OTEL_EXPORTER_OTLP_PROTOCOL="http/protobuf"
export OTEL_EXPORTER_OTLP_HEADERS="Authorization=Basic%20$(printf '%s:%s' '@logs_id-otel' '<your-api-key>' | base64 | tr -d '\n')"
```

</Tab>
<Tab>

```powershell copy /@logs_id/
$env:OTEL_SERVICE_NAME = "my-service"
$env:OTEL_PHP_AUTOLOAD_ENABLED = "true"
$env:OTEL_TRACES_EXPORTER = "otlp"
$env:OTEL_METRICS_EXPORTER = "otlp"
$env:OTEL_LOGS_EXPORTER = "otlp"
$env:OTEL_EXPORTER_OTLP_ENDPOINT = "https://@logs_id-otel.logit.io"
$env:OTEL_EXPORTER_OTLP_PROTOCOL = "http/protobuf"
$pair = "@logs_id-otel:<your-api-key>"
$env:OTEL_EXPORTER_OTLP_HEADERS = "Authorization=Basic%20" + [Convert]::ToBase64String([Text.Encoding]::UTF8.GetBytes($pair))
```

</Tab>
</Tabs>

<Steps>
  ## Extension and SDK

  ```bash copy
  pecl install opentelemetry
  ```

  `php.ini`: `extension=opentelemetry.so`

  ```bash copy
  composer require open-telemetry/sdk
  ```

  The Slim getting started example also requires `open-telemetry/opentelemetry-auto-slim`. Use the auto-instrumentation package for the framework you actually run, not Slim unless the app is Slim.

  Set `OTEL_PHP_AUTOLOAD_ENABLED=true`. Set `OTEL_TRACES_EXPORTER=otlp`, `OTEL_METRICS_EXPORTER=otlp` and `OTEL_LOGS_EXPORTER=otlp` with the shared `OTEL_EXPORTER_OTLP_*` variables.

  The logs example uses `monolog/monolog` and `open-telemetry/opentelemetry-logger-monolog` with `OpenTelemetry\Contrib\Logs\Monolog\Handler`.

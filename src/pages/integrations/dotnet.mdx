Send logs, traces and metrics from a .NET app to Hosted OpenTelemetry. One endpoint and one credential. Do not install `otelcol-contrib` for this path.

## Endpoint

- Endpoint: `https://@logs_id-otel.logit.io` (no port)
- Protocol: `http/protobuf`
- Username: `@logs_id-otel`
- API key: the key on the Hosted OpenTelemetry card (Settings, Endpoints). Replace `<your-api-key>`. Do not commit that key.
- Header: `Authorization=Basic%20` plus the Base64 of `username:api-key`. The .NET exporter accepts the percent-encoded space. Do not rewrite it to a raw space.

`@logs_id` is your logs stack id. Do not pass the bare host as `Endpoint`. If `Endpoint` is set in code, the exporter does not append `/v1/logs`, `/v1/traces` and `/v1/metrics`. Do not use gRPC to this host.

Set the variables on the process that runs the app (`launchSettings.json`, Azure App Service application settings, container environment, IIS `environmentVariables`, systemd, or a Windows service). An export in the current terminal only applies to a local run in that same window.

<Tabs items={["Linux and macOS", "Windows PowerShell"]}>
<Tab>

```bash copy /@logs_id/
export OTEL_SERVICE_NAME="my-service"
export OTEL_EXPORTER_OTLP_ENDPOINT="https://@logs_id-otel.logit.io"
export OTEL_EXPORTER_OTLP_PROTOCOL="http/protobuf"
export OTEL_EXPORTER_OTLP_HEADERS="Authorization=Basic%20$(printf '%s:%s' '@logs_id-otel' '<your-api-key>' | base64 | tr -d '\n')"
```

</Tab>
<Tab>

```powershell copy /@logs_id/
$env:OTEL_SERVICE_NAME = "my-service"
$env:OTEL_EXPORTER_OTLP_ENDPOINT = "https://@logs_id-otel.logit.io"
$env:OTEL_EXPORTER_OTLP_PROTOCOL = "http/protobuf"
$pair = "@logs_id-otel:<your-api-key>"
$env:OTEL_EXPORTER_OTLP_HEADERS = "Authorization=Basic%20" + [Convert]::ToBase64String([Text.Encoding]::UTF8.GetBytes($pair))
```

</Tab>

<Steps>
  ## Register with UseOtlpExporter

  ```bash copy
  dotnet add package OpenTelemetry.Extensions.Hosting
  dotnet add package OpenTelemetry.Exporter.OpenTelemetryProtocol
  dotnet add package OpenTelemetry.Instrumentation.AspNetCore
  dotnet add package OpenTelemetry.Instrumentation.Http
  ```

  `UseOtlpExporter()` enables the OTLP exporter for logs, metrics and traces and reads `OTEL_EXPORTER_OTLP_ENDPOINT`, `OTEL_EXPORTER_OTLP_PROTOCOL` and `OTEL_EXPORTER_OTLP_HEADERS`.

  ```csharp copy
  builder.Services.AddOpenTelemetry()
      .WithTracing(tracing => tracing
          .AddAspNetCoreInstrumentation()
          .AddHttpClientInstrumentation())
      .WithMetrics(metrics => metrics
          .AddAspNetCoreInstrumentation()
          .AddHttpClientInstrumentation())
      .UseOtlpExporter();

  builder.Logging.AddOpenTelemetry(logging =>
  {
      logging.IncludeScopes = true;
  });
  ```

  ## Zero-code profiler

  Zero-code is a separate install. It is not "no code changes".

  On Linux or macOS, run `otel-dotnet-auto-install.sh` and source `instrument.sh`. On Windows, use PowerShell 5.1, `OpenTelemetry.DotNet.Auto.psm1`, `Install-OpenTelemetryCore`, then `Register-OpenTelemetryForCurrentSession`, `Register-OpenTelemetryForWindowsService`, or `Register-OpenTelemetryForIIS`. Put the same `OTEL_*` variables on that process.

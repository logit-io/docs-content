Send logs, traces and metrics from a Go app to Hosted OpenTelemetry. Go has no zero-code agent in this setup. Do not install `otelcol-contrib` for this path.

## Endpoint

- Endpoint: `https://@logs_id-otel.logit.io` (no port)
- Protocol: `http/protobuf`
- Username: `@logs_id-otel`
- API key: the key on the Hosted OpenTelemetry card (Settings, Endpoints). Replace `<your-api-key>`. Do not commit that key.
- Header: `Authorization=Basic%20` plus the Base64 of `username:api-key`.

`@logs_id` is your logs stack id. Use the HTTP exporters `otlptracehttp`, `otlpmetrichttp` and `otlploghttp`. Do not import `otlptracegrpc`, `otlpmetricgrpc` or `otlploggrpc` for the Logit host. Do not call `WithEndpoint` with the bare host. Do not use gRPC to this host.

Set the variables on the process that runs the app. An export in the current terminal only applies to a local run in that same window.

<Tabs items={["Linux and macOS", "Windows PowerShell"]}>
<Tab>

```bash copy /@logs_id/
export OTEL_SERVICE_NAME="my-service"
export OTEL_TRACES_EXPORTER="otlp"
export OTEL_METRICS_EXPORTER="otlp"
export OTEL_LOGS_EXPORTER="otlp"
export OTEL_EXPORTER_OTLP_ENDPOINT="https://@logs_id-otel.logit.io"
export OTEL_EXPORTER_OTLP_PROTOCOL="http/protobuf"
export OTEL_EXPORTER_OTLP_HEADERS="Authorization=Basic%20$(printf '%s:%s' '@logs_id-otel' '<your-api-key>' | base64 | tr -d '\n')"
```

</Tab>
<Tab>

```powershell copy /@logs_id/
$env:OTEL_SERVICE_NAME = "my-service"
$env:OTEL_TRACES_EXPORTER = "otlp"
$env:OTEL_METRICS_EXPORTER = "otlp"
$env:OTEL_LOGS_EXPORTER = "otlp"
$env:OTEL_EXPORTER_OTLP_ENDPOINT = "https://@logs_id-otel.logit.io"
$env:OTEL_EXPORTER_OTLP_PROTOCOL = "http/protobuf"
$pair = "@logs_id-otel:<your-api-key>"
$env:OTEL_EXPORTER_OTLP_HEADERS = "Authorization=Basic%20" + [Convert]::ToBase64String([Text.Encoding]::UTF8.GetBytes($pair))
```

</Tab>

<Steps>
  ## autoexport

  `autoexport` keeps the endpoint in environment variables.

  ```bash copy
  go get go.opentelemetry.io/otel
  go get go.opentelemetry.io/contrib/exporters/autoexport
  go get go.opentelemetry.io/contrib/instrumentation/net/http/otelhttp
  go get go.opentelemetry.io/otel/exporters/otlp/otlptrace/otlptracehttp
  go get go.opentelemetry.io/otel/exporters/otlp/otlpmetric/otlpmetrichttp
  go get go.opentelemetry.io/otel/exporters/otlp/otlplog/otlploghttp
  ```

  ```go copy
  spanExporter, err := autoexport.NewSpanExporter(ctx)
  tracerProvider := sdktrace.NewTracerProvider(sdktrace.WithBatcher(spanExporter))
  metricReader, err := autoexport.NewMetricReader(ctx)
  meterProvider := sdkmetric.NewMeterProvider(sdkmetric.WithReader(metricReader))
  logExporter, err := autoexport.NewLogExporter(ctx)
  handler := otelhttp.NewHandler(mux, "/")
  ```

  Set `OTEL_TRACES_EXPORTER=otlp`, `OTEL_METRICS_EXPORTER=otlp` and `OTEL_LOGS_EXPORTER=otlp`. Logs are experimental in the getting started steps. `otelhttp.NewHandler` is the net/http instrumentation those steps show.

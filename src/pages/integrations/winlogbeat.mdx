Ship Windows event logs to Logit.io with Winlogbeat: install the agent as a Windows service, point it at your Logstash endpoint, and view Security / System / Application events in OpenSearch Dashboards.

Winlogbeat is a Windows-specific event-log shipping agent. Use it for security logging, failed-logon investigations, and SIEM-style workflows on managed OpenSearch.

  ### Start winlogbeat

  From the PowerShell prompt, (in the directory where winlogbeat was installed) run the following command:

  ```ps1 copy
  Start-Service winlogbeat
  ```
